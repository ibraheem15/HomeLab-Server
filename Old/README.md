# Archived Home Lab Notes

These directories contain the previous generation of the home lab wiki. They are retained to show the project’s evolution and for historical reference only.

> **Do not deploy these examples unchanged.** Some pages use superseded architecture, broad permissions, root containers, placeholder passwords, direct port publishing, or older product procedures. The archive has been sanitized for publication, but it has not been modernized into current guidance.

Use the [current wiki](../New/README.md) for the authoritative architecture, deployment patterns, operations, and recovery procedures.
