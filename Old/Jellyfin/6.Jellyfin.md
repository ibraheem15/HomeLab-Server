# Jellyfin Media Server Installation with Docker

## Prerequisites

- Docker installed on your system
- (Optional) Docker Compose

## Follow these steps to install Jellyfin using Docker:

### 1. Create Required Directories

```bash
mkdir -p ~/jellyfin/config ~/jellyfin/cache ~/jellyfin/media
```

### 2. Run Jellyfin with Docker Using Docker Compose

- We will use Docker Compose for easier management
- Get PUID and PGID of your user:

```bash
id
```

```bash
# Example output:
uid=1000(yourusername) gid=1000(yourgroup) groups=1000(yourgroup),...
```

- Use the PUID and PGID in the Docker Compose file
  Create a file named `docker-compose.yml` in the `~/jellyfin` directory with the following content:

```yaml
version: "3.8"
services:
  jellyfin:
    image: jellyfin/jellyfin
    container_name: jellyfin
    environment:
      - PUID=1000
      - PGID=1000
    ports:
      - 8096:8096
    volumes:
      - ./config:/config
      - ./cache:/cache
      - ./media:/media
    restart: unless-stopped
```

### 3. Adjust Permissions

Ensure the directories have the correct permissions:

```bash
sudo chown -R 1000:1000 ~/jellyfin
sudo chmod -R 755 ~/jellyfin
```

### 4. Start Jellyfin

Navigate to the directory where your `docker-compose.yml` file is located and run:

```bash
docker compose up -d
```

## 5. Access Jellyfin

After the container is up and running, you can access Jellyfin through your web browser.

Open your browser and go to: [http://<tailscale-ip>:8096](http://<tailscale-ip>:8096)

## 6. Initial Setup

Follow the setup wizard to complete configuration.

Username: `admin`
Password: use a unique password from a password manager

## 7. Enable Reverse Proxy

- Add the following to your Caddyfile:

```plaintext
jellyfin.example.com {
  reverse_proxy http://<tailscale-ip>:8096
  tls internal
}

```

### 8. Restart Caddy

```bash
sudo systemctl restart caddy
```

## 9. Add to Pi-hole
- Open DNS Local Records
- Add the following entries:
```
jellyfin.example.com    <tailscale-ip>
www.jellyfin.example.com    <tailscale-ip>
```

### 10. Add OpenSubtitles
- Go to [OpenSubtitles](https://www.opensubtitles.org/) and create an account.
- In Jellyfin, go to `Dashboard` > `Catalog` and install the OpenSubtitles plugin.
### 12. Configure OpenSubtitles Plugin
- Go to `Dashboard` > `Plugins` > `OpenSubtitles` and enter your OpenSubtitles credentials.
