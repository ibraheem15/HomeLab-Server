# Pi-hole Installation and Custom DNS Configuration Guide (Optional)

## Overview
Pi-hole is a network-wide ad blocker that acts as a DNS sinkhole. This guide covers installation and custom DNS setup.

## Prerequisites
- System Requirements:
  - Static IP address configured
  - Ports 53 (DNS) and 80 (Web interface) available
  - No conflicting services on port 80:
    ```bash
    # Stop and disable Apache/Nginx if running
    sudo systemctl stop apache2
    sudo systemctl disable apache2
    ```
- Tailscale installed and configured on the server
- Remove any existing DNS services like `dnsmasq` to avoid conflicts:
  ```bash
  sudo systemctl stop dnsmasq
  sudo systemctl disable dnsmasq
  ```


## Installation

1. Run the official installer:
```bash
curl -sSL https://install.pi-hole.net | bash
```

2. Follow the installation wizard
- Choose network interface (Tailscale0)
- Select upstream DNS provider (Google)
- Configure static IP address (done before installation)
- Save Password for web interface somewhere safe

## Web Interface Setup
- Go to pihole.toml in `/etc/pihole/` and set the following in the `[webserver]` section (look for webserver.port setting):
```toml
port = "5000o,5001os,[::]:5000o,[::]:5001os" 
```
- This allows Pi-hole to run on port 5000 for HTTP and 5001 for HTTPS, avoiding conflicts with Caddy on port 80 and 443.
- Restart Pi-hole to apply changes:
```bash
sudo systemctl restart pihole-FTL
```
- Go to `/etc/caddy/Caddyfile` and add the following for reverse proxy:
```plaintext
pihole.example.com {
    reverse_proxy http://<tailscale-ip>:5000
    tls internal
}

# Redirect HTTP to HTTPS
http://pihole.example.com {
    redir https://pihole.example.com{uri}
    tls internal
}
```
- Restart Caddy to apply changes:
```bash
sudo systemctl restart caddy
```
## Post-Installation Steps
### Accessing the Web Interface
1. Note the admin password shown after installation
2. Access web interface: `https://pihole.example.com/admin`
2.1 If this does not work, try:
```
https://<tailscale-ip>/admin
```
3. Login with password

    #### DNS Configuration
    - Turn Expert Mode on for advanced options in DNS settings
      - In interface settings, enable "Respond only on interface tailscale0"

## Custom DNS Configuration

### Adding Custom DNS Records
1. Go to "Settings" > "Local DNS Records"
2. Add entries in format:
```
example.com    <tailscale-ip>
```
- These entries will be same as in Caddyfile for reverse proxy

## Tailscale Override DNS
- Go to Tailscale admin panel
- Navigate to "DNS" settings
- In global nameservers, add Tailscale IP of your server
- Select Override DNS Servers
  - This will ensure that all DNS queries from your Tailscale network are routed through your Pi-hole instance.

## Ad Blocking
- Change ad blocking list in the web interface under "Lists"
- Add custom blocklists 
  - https://raw.githubusercontent.com/hagezi/dns-blocklists/main/adblock/pro.txt


## Maintenance
- Update regularly: `pihole -up`
- Check logs: `pihole -t`
- Update gravity: `pihole -g`
