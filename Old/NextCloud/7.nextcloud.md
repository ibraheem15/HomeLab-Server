# Installing Nextcloud with Docker

## Prerequisites
- [Docker](https://docs.docker.com/get-docker/) installed
- [Docker Compose](https://docs.docker.com/compose/install/) installed

## Steps to Install Nextcloud

### 1. Create a `docker-compose.yml` file in Home Directory 

```yaml
services:
  nextcloud:
    image: nextcloud:latest
    container_name: nextcloud
    environment:
      - PUID=0 # Root user ID for consistency with Jellyfin
      - PGID=0 # Root group ID
      - TZ=<IANA_TIMEZONE> # Your timezone
      - MYSQL_HOST=db
      - MYSQL_DATABASE=nextcloud
      - MYSQL_USER=nextcloud
      - MYSQL_PASSWORD=<SECRET> # Replace with a secure password
      - REDIS_HOST=redis
    volumes:
      - ./nextcloud_data:/var/www/html
    ports:
      # expose Nextcloud on different ports to avoid conflicts 
      - "5080:80"  # HTTP
      - "5443:443" # HTTPS
    restart: unless-stopped
    depends_on:
      - db
      - redis
    networks:
      - nextcloud_network

  db:
    image: mariadb:11.4-ubi
    container_name: nextcloud_db
    environment:
      - MYSQL_ROOT_PASSWORD=<SECRET> # Replace with a secure password
      - MYSQL_DATABASE=nextcloud
      - MYSQL_USER=nextcloud
      - MYSQL_PASSWORD=<SECRET> # Same as MYSQL_PASSWORD above
    volumes:
      - ./db_data:/var/lib/mysql
    restart: unless-stopped
    networks:
      - nextcloud_network

  redis:
    image: redis:latest
    container_name: nextcloud_redis
    restart: unless-stopped
    networks:
      - nextcloud_network

networks:
  nextcloud_network:
    driver: bridge
```

### 2. Start Nextcloud

```sh
docker compose up -d
```

### 3. Access Nextcloud

Open your browser and go to: [http://<tailscale-ip>:5080]

### 4. Configure Nextcloud
- Open '/root/nextcloud/nextcloud_data/config/config.php' and add the following lines to the `trusted_domains` array:
```php
'trusted_domains' => 
  array (
    0 => 'localhost',
    1 => 'nextcloud.example.com',
  )
```

### 5. Caddy Configuration
- Open `/etc/caddy/Caddyfile` and add the following for reverse proxy:

```plaintext
nextcloud.example.com {
  reverse_proxy http://<tailscale-ip>:5080
  tls internal
}

http://nextcloud.example.com {
  redir https://nextcloud.example.com{uri}
  tls internal
}
```
### 6. Restart Caddy

```sh
sudo systemctl restart caddy
```

### 7. Add Custom DNS Records
- Go to "Settings" > "Local DNS Records" in Pi-hole
- Add entries in the format:
```
example.com    <tailscale-ip>
```
- These entries will be the same as in Caddyfile for reverse proxy.

### 8. Access Nextcloud Web Interface
- Go to `https://nextcloud.example.com` in your browser

### 9. Shared Folders between Nextcloud and Jellyfin
- To share folders between Nextcloud and Jellyfin, you can create a shared folder in root directory and mount it in both containers.

- Update the `docker-compose.yml` file of Nextcloud to include the shared directory:

```yaml
    volumes:
      - ./nextcloud_data:/var/www/html
      - /root/jellyfin/media:/mnt/jellyfin_media # Shared directory for Jellyfin
```

- This will create a shared directory at `Shared` in the Nextcloud container, which can be accessed by Jellyfin as well.

- Restart both containers to apply changes:

```sh
docker-compose down
docker-compose up -d
```

### 10. Scan Files in Nextcloud

```sh
docker exec -it -u www-data nextcloud php /var/www/html/occ files:scan --all
```

### 11. Give Permissions to Nextcloud for Writing to Shared Directory

```sh
ls -ld /home/<USER>/jellyfin/media
ls -l /home/<USER>/jellyfin/media
chown -R root:www-data /home/<USER>/jellyfin/media
chmod -R 777 /home/<USER>/jellyfin/media

chown -R root:www-data /home/<USER>/drive2
chmod -R 777 /home/<USER>/drive2

docker exec -it nextcloud bash
ls -ld /mnt/jellyfin_media
ls -l /mnt/jellyfin_media

chown -R www-data:www-data /mnt/jellyfin_media
chmod -R 777 /mnt/jellyfin_media

chown -R www-data:www-data /mnt/drive2
chmod -R 777 /mnt/drive2

chown -R www-data:www-data /var/www/html/data/admin/uploads
chmod -R 777 /var/www/html/data/admin/uploads
exit
```

### 12. Set Up Server Side Encryption
- In Nextcloud, go to "Administrative Settings" > "Security" and enable server-side encryption.
- Go to "Apps" and enable the "Default encryption module" app.
- This will ensure that files uploaded to Nextcloud are encrypted, enhancing security.

### 13. Enable External Storage Support
- In Nextcloud, go to "Apps" and enable the "External storage support" app.

### 14. Add Shared Directory to Nextcloud
- In Nextcloud, go to "Settings" > "External Storage"
- Add a new external storage with the following settings:
  - **Folder name**: Jellyfin
  - **External Storage**: Local
  - **Configuration**: `/mnt/jellyfin_media`
  - **Available for**: All users or specific users/groups as needed
  - **Encrypted**: No

- Click "Save" to add the shared directory to Nextcloud.
- This will allow you to access the Jellyfin media files directly from Nextcloud, making it easier to manage and share files across both applications.


- This will ensure that Nextcloud can write to the shared directory, allowing you to manage files seamlessly between Nextcloud and Jellyfin.

### Permissions fix if file added from outside the container

```bash
docker exec nextcloud /bin/bash -c "chown -R www-data:www-data /mnt/jellyfin_media && chmod -R 775 /mnt/jellyfin_media && chown -R www-data:www-data /var/www/html/data/admin/uploads && chmod -R 775 /var/www/html/data/admin/uploads"
```
