# Install Immich with Docker

Follow these steps to install [Immich](https://immich.app/docs/overview/quick-start) using Docker:

## Post-Installation Steps
1. **Start the Docker Containers**:
   Open a terminal in the directory where you created the `docker-compose.yml` file and run:
   ```bash
   docker-compose up -d
   ```
2. **Access Immich**:
    Open your web browser and navigate to `http://<tailscale-ip>:3000` to access the Immich web interface.
3. **Cadmy Configuration**:
   - Open `/etc/caddy/Caddyfile` and add the following configuration for reverse proxy:
   ```plaintext
   immich.example.com {
     reverse_proxy http://<tailscale-ip>:2283
     tls internal
    }
    http://immich.example.com {
      redir https://immich.example.com{uri}
      tls internal
    }
    ```
4. **Restart Caddy**:
    ```bash
    sudo systemctl restart caddy
    ```
5. **Add Custom DNS Records**:
   - Go to "Settings" > "Local DNS Records" in Pi-hole.
   - Add entries in the format:
     ```
     immich.example.com -> <tailscale-ip>
     ```
