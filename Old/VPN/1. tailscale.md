# Installing Tailscale on Linux

To install Tailscale on Linux using curl, run the following command:

```bash
curl -fsSL https://tailscale.com/install.sh | sh
```

This command will:
1. Download the installation script
2. Execute it with root privileges
3. Install the Tailscale package
4. Set up the necessary system services

## Start Tailscale
To start Tailscale, run the following command:

```bash
tailscale up
```

This command will:
- Start the Tailscale service
- Prompt you to log in with your Tailscale account
- Authorize the device to connect to your Tailscale network

## Set Tailscale with SSH enabled (optional)
If you want to enable SSH access to the device over Tailscale (use as remote server in vscode), you can start Tailscale with SSH enabled by running the following command:

```bash
tailscale set -ssh
```

## Verify Installation
To verify that Tailscale is installed and running, run the following command:

```bash
tailscale status
```

This command will display the status of the Tailscale service, including the device's IP address and connection status.

## Get Tailscale IP Address
To get the Tailscale IP address of the device, run the following command:

```bash
tailscale ip 
```
This command will return the IPv4 address assigned to the device by Tailscale.

## SSH into Tailscale Device
To SSH into the Tailscale device, use the following command:

```bash
ssh <tailscale-username>@<tailscale-ip>
```

Replace `<tailscale-username>` with your Tailscale username and `<tailscale-ip>` with the Tailscale IP address obtained from the previous command.

## Ping Tailscale Device
To ping the Tailscale device, you first need to connect to the Tailscale network. Once connected, you can ping the device using its Tailscale IP address:

```bash
ping <tailscale-ip-of-vm>
```

Once the device is added to your Tailscale network, you can access it from other devices on the network using the Tailscale IP address or MagicDNS (domain provided by Tailscale but can only be used with Tailscale VPN enabled).
