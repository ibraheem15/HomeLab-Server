# Aria2 & AriaNg Installation & Integration Guide

## 1. Install Aria2 & AriaNg (Docker)

Add the following service to your `compose.yml` (example for integration with Jellyfin):

```yaml
services:
  ariang:
    image: hurlenko/aria2-ariang
    container_name: ariang
    ports:
      - "6880:8080" # AriaNg web UI port
      - "6800:6800" # Aria2 RPC port
    volumes:
      - /home/<USER>/jellyfin/media:/aria2/data # Shared with Jellyfin's /media
      # /aria2/data/Movies will map to /home/<USER>/jellyfin/media/Movies
      - /home/<USER>/aria2/ariang-conf:/aria2/conf # Aria2 configuration
    environment:
      - PUID=1000
      - PGID=1000
      - RPC_SECRET=<SECRET>
      # This specific variable injects the secret into the HTML/JS automatically:
      - EMBED_RPC_SECRET=true
      # This sets the default port in the UI to match your Caddy port:
      - ARIA2RPCPORT=443
    restart: always
```

## 2. Add Aria2 URL to Pi-hole

1. Open Pi-hole admin panel.
2. Go to **Group Management > Local DNS Records**.
3. Add `aria2.example.com` to the list.

## 3. Configure Caddy for Aria2 & AriaNg

Add a site block in your Caddyfile:

```caddyfile
aria2.example.com {
  reverse_proxy http://<tailscale-ip>:6880
  tls internal
}

http://aria2.example.com {
  redir https://aria2.example.com{uri}
  tls internal
}
```

Reload Caddy after editing.

```bash
sudo systemctl reload caddy
```

## 4. Reference in Jellyfin Docker Compose

Ensure both `jellyfin` and `ariang` services are on the same Docker network (e.g., `jellyfin_network`).

---

**Summary:**

- Deploy Aria2 & AriaNg via Docker.
- Add `aria2.example.com` to Pi-hole.
- Set up Caddy reverse proxy.
- Link Aria2/AriaNg and Jellyfin via shared network and volumes.
