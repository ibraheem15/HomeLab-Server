# Installing Caddy Web Server on Debian

## Prerequisites

- Clear port 80 and 443 on your server.

```bash
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw reload
```

## Configuration Steps

1. First, update your package list:

```sh
sudo apt update
```

2. Then, install the necessary dependencies:

```sh
sudo apt install -y debian-keyring debian-archive-keyring apt-transport-https
```

3. Add the Caddy repository and its GPG key:

```sh
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' | sudo gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' | sudo tee /etc/apt/sources.list.d/caddy-stable.list
```

4. Update your package list again and install Caddy:

```sh
sudo apt update
sudo apt install caddy
```

## Verify Installation

Check the installed version:

```sh
caddy version
```

## Basic Usage

Start Caddy with a simple file server:

```sh
caddy run
```

## Check Caddy on Browser

Open your web browser and navigate to:

```
http://<your-server-ip>
```

You should see the Caddy welcome page.
