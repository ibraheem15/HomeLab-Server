# Installing Portainer on Docker

## Prerequisites
- Docker installed on the host machine
- Root access or sudo privileges

## Installation Steps

1. Create a volume for Portainer data:
```bash
docker volume create portainer_data
```

2. Run Portainer container:
```bash
docker run -d -p 8000:8000 -p 9443:9443 --name portainer --restart=always -v /var/run/docker.sock:/var/run/docker.sock -v portainer_data:/data portainer/portainer-ce:lts
```

3. Check the status of the container:
```bash
docker ps
```

4. Access Portainer in a web browser:
```
https://<my-ip>:9443
```
- replace `<my-ip>` with your server's IP address.

5. Complete the setup wizard by setting a password and creating an admin user.

- username: admin
- password: (set during setup) (minimum 12 characters)
  - use a unique password from a password manager

6. Click "Create user" and log in with the admin credentials.

7. Add Portainer to Caddyfile

```caddyfile
https://portainer.example.com {
    reverse_proxy https://<tailscale-ip>:9443 {
        transport http {
            tls_insecure_skip_verify
        }
    }
    tls internal
}
```
