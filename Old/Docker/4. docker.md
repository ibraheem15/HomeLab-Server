# Installing Docker on Ubuntu Server

## Prerequisites
- Debian (11 or later) or Ubuntu (20.04 or later)
- A server with at least 2GB of RAM
- Root access or sudo privileges

## Installation Steps

- It is recommended to install Docker using the official installation script provided by Docker on their website, which ensures you get the latest version and dependencies.

### https://docs.docker.com/engine/install/debian/

1. Update package index:
```bash
apt update
```

2. Install required packages:
```bash
apt install -y ca-certificates curl 
```

3. Follow the official Docker installation guide for Debian:
```bash
https://docs.docker.com/engine/install/debian/
```

4. Verify installation:
```bash
sudo docker run hello-world
```

5. (Optional) Add user to docker group:
```bash
sudo usermod -aG docker ${USER}
```

> Note: Log out and back in for group changes to take effect.
