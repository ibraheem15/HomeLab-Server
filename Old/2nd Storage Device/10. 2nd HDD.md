# Installing and Mounting a Second HDD

## 1. Attach Cables in Hardware

1. **Power Off the Computer**  
  Shut down your PC and unplug it from the power source.

2. **Open the Case**  
  Remove the side panel to access the internal components.

3. **Insert the HDD**  
  Slide the new HDD into an available drive bay and secure it with screws.

4. **Connect the SATA Data Cable**  
  Attach one end of the SATA data cable to the HDD and the other end to an available SATA port on the motherboard. (Small port (7-pin) = SATA Data connector (goes to motherboard / SATA controller).)

5. **Connect the Power Cable**  
  Plug a SATA power connector from the power supply into the HDD. (Large port (15-pin) = SATA Power connector (from PSU))

6. **Close the Case and Power On**  
  Replace the side panel, plug in the power cable, and turn on your computer.

---

## 2. Mount the HDD in the Operating System
### On Linux

1. **Identify the New Drive**  
  Run:  
  ```bash
  sudo fdisk -l
  ```

2. **Partition and Format (if needed)**  
  Use `fdisk` or `gparted` to create a partition, then format:  
  ```bash
  sudo mkfs.ext4 /dev/sdX1
  ```

3. **Create a Mount Point**  
  ```bash
  sudo mkdir /home/user/newhdd
  ```

4. **Mount the Drive**  
  ```bash
  sudo mount /dev/sdb1 /home/user/newhdd
  ```

5. **(Optional) Add to /etc/fstab for Auto-mount**
   Edit the fstab file:
   ```bash
   sudo nano /etc/fstab
   ```
   Add the following line:
   ```
   /dev/sdb1 /home/user/newhdd ext4 defaults 0 2
   ```

---

Your second HDD is now installed and mounted.
