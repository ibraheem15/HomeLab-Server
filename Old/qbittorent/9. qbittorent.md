# qBittorrent Installation & Integration Guide

## 1. Install qBittorrent (Docker)

Add the following service to your `docker-compose.yml` (example for integration with Jellyfin):

```yaml
services:
  qbittorrent:
    image: linuxserver/qbittorrent:latest
    container_name: qbittorrent
    environment:
      - PUID=0 # Match Jellyfin's PUID for consistent permissions
      - PGID=0 # Match Jellyfin's PGID
      - TZ=<IANA_TIMEZONE>
      - WEBUI_PORT=8080 # qBittorrent web UI port
    volumes:
      - ./qbittorrent_config:/config # qBittorrent configuration
      - /home/user/jellyfin/media:/downloads # Shared with Jellyfin's /media
    ports:
      - 5072:8080 # qBittorrent web UI port
      - 6881:6881 # Torrent port
      - 6881:6881/udp # Torrent port (UDP)
    restart: unless-stopped

networks:
  jellyfin_network:
    external: true
```

## 2. Add qBittorrent URL to Pi-hole

1. Open Pi-hole admin panel.
2. Go to **Group Management > Local DNS Records**.
3. Add `torrent.example.com` to the list.

## 3. Configure Caddy for qBittorrent

Add a site block in your Caddyfile:

```caddyfile

torrent.example.com {
  reverse_proxy http://<tailscale-ip>:5072
  tls internal
}

http://torrent.example.com {
  redir https://torrent.example.com{uri}
  tls internal
}

```

Reload Caddy after editing.

```bash
sudo systemctl reload caddy
```

## 4. Reference in Jellyfin Docker Compose

Ensure both `jellyfin` and `qbittorrent` services are on the same Docker network (`jellyfin_network`).

---

**Summary:**  
- Deploy qBittorrent via Docker.  
- Add `torrent.example.com` to Pi-hole.  
- Set up Caddy reverse proxy.  
- Link qBittorrent and Jellyfin via shared network and volumes.
